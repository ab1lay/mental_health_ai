# Архитектура системы Mental Health AI

## 1. Текущая реализация (Text Baseline)

Система построена на микросервисной архитектуре с использованием **LangGraph** для управления потоком обработки данных.

### Компоненты:
- **Telegram Bot (Interface Layer):** Принимает сообщения от пользователя, отправляет ответы. Реализован на `python-telegram-bot`.
- **Orchestrator (LangGraph):** Управляет состоянием диалога (StateGraph).
  - `preprocess_node`: Очистка текста.
  - `analyze_node`: LLM (GPT-4o/GPT-3.5) для извлечения эмоций, оценки рисков и генерации резюме.
  - `respond_node`: Форматирование ответа с визуализацией шкал риска.
- **Data Layer:** Pydantic-схемы (`EmotionResult`) для строгой типизации данных.

## 2. План интеграции мультимодальности (Audio & Video)

Для реализации целей исследования (анализ аудио и видео) предлагается следующая архитектура расширения:

### Аудио-модуль
1. **Input:** Голосовые сообщения Telegram (OGG/OGA).
2. **Processing:**
   - Конвертация OGG -> WAV (`ffmpeg`).
   - Транскрибация (STT): OpenAI Whisper / Faster-Whisper.
   - Извлечение просодических признаков (тон, темп, паузы): `librosa`, `opensmile`.
3. **Integration:**
   - Текст из STT подается в `analyze_node` (как сейчас).
   - Акустические признаки подаются в отдельный классификатор (или в промпт LLM как метаданные).

### Видео-модуль
1. **Input:** Видеосообщения (Telegram Video Notes).
2. **Processing:**
   - Извлечение кадров (1-2 кадра в секунду).
   - Анализ мимики (Facial Expression Recognition): DeepFace / FER.
   - Анализ позы/жестов: MediaPipe.
3. **Fusion:**
   - Late Fusion: Объединение скоров от текста, аудио и видео (взвешенная сумма).
   - Early Fusion: Подача всех векторов признаков в единую мультимодальную модель.

## 3. Оценка рисков (Risk Reasoning)
Текущая система использует LLM для квантификации:
- **Depression Score (0.0 - 1.0)**
- **Anxiety Score (0.0 - 1.0)**
- **Stress Score (0.0 - 1.0)**

Эти показатели визуализируются пользователю и могут служить триггерами для рекомендации обратиться к специалисту (при score > 0.7).
